# RoboCup

Разработка полностью автономного мобильного робота для участия в международных соревнованиях **RoboCup Junior Soccer**. Робот предназначен для самостоятельного обнаружения инфракрасного мяча, навигации по полю, дриблинга и забивания голов.

## О проекте

Проект представляет собой трехколесную омни-платформу под управлением Raspberry Pi + Arduino Mega. 

**Ключевые возможности:**
*   **Омни-движение:** Перемещение в любом направлении без разворота корпуса.
*   **Компьютерное зрение:** Обнаружение ворот и навигация с помощью широкоугольной камеры и OpenCV.
*   **ИК-навигация:** Круговой массив из 16 сенсоров TCRT5000 для поиска мяча.
*   **Кикер:** Электромагнитный ударный механизм (соленоид 48V).
